SuperDial

A display-only round face with any number of pointers, a scale that sweeps or wraps, custom tick labels, a zone ring and a face that can turn. A clock, a compass with a turning card and a circular gauge are the same control with different settings.

Display onlysrc/SuperDial.h

Quick start

SuperDial clockFace(&lcd, 5, 5, 150, 150, &lgfx::fonts::Font2);
clockFace.MakeClock();                       // 12 hour face, three pointers (hours, minutes, seconds)
SuperDial compass(&lcd, 165, 5, 150, 150, &lgfx::fonts::Font2);
compass.MakeCompass();                   // N E S W card, a red pointer at the top
SuperDial tacho(&lcd, 5, 175, 200, 140, &lgfx::fonts::Font2);
tacho.SetSweep(0, 8, -135, 135);         // 0..8 over 270 degrees
tacho.AddZone(6, 8, TFT_RED);
tacho.AddPointer();
form.Add(&clockFace, false); form.Add(&compass, false); form.Add(&tacho, false);
clockFace.SetTime(10, 8, 30);                // from your own clock
compass.SetHeading(40);                  // the card turns, the pointer stays at the top
tacho.SetPointerValue(0, 5.5f);

Unique features

  • Scale. SetSweep(min, max, startDeg, endDeg) maps a value range onto an arc (values are clamped). SetWrap(range) maps 0..range onto the whole circle and the values wrap: 359 to 1 goes through 0, not back through 180.
  • Pointers. AddPointer(length, width, colour, style, onCard) returns the index; SetPointerValue(i, v) moves it. Styles: POINTER_TAPER, POINTER_LINE, POINTER_TAIL (with a short tail behind the hub). Later pointers are drawn on top.
  • Face. Rim, zone ring (AddZone, ZoneThickness), ticks and labels. SetFaceRotation(deg) turns the ticks, zones and labels; the labels move but stay upright. A pointer added with onCard = true turns with the face (a bearing on a compass card).
  • Labels. SetTickLabels({"N","NE",...}) replaces the numbers at the major ticks (an empty string leaves a tick bare). A wrap scale shows the range's end at the top (12, not 0).
  • Hub. ShowValue writes the value of pointer ValuePointer (default 0) in a box over the hub (ValueInHub), with SetFormat(decimals, unit) or SetHubText().
  • Presets. MakeClock() + SetTime(h, m, s) and MakeCompass() + SetHeading(deg) set up those two faces.
  • Smoothing is on by default: pointers and the face glide (the short way round on a wrap scale). All the maths is single precision; the face's sines and cosines are worked out once per tick set and rotated per frame.

GUI workflow

Display only: nothing to operate. The user sees the pointers glide to new values and the card turn.

Event workflow

BeforeDraw (a pull event): SetOnBeforeDraw(fn, user) and SetPollMs(ms). Your function is called from Tick() every ms milliseconds (0 = on every service pass; the first call is at once). Put the code that reads the clock or sensor in it and call SetPointerValue(), SetTime(), SetHeading(), SetFaceRotation(), SetHubText() or set ValuePointer. Nothing is drawn while it runs and the dial redraws only if something changed, so setting the same values again is free. You can also feed the dial from loop() instead. Animation is driven by SuperControl::Tick() from SuperForm::Service(); without a form call Update() from loop().

Tips and tricks

TipCompass: keep the pointer at the top and turn the card with SetHeading(); that is how a real compass card reads.
TipClock: turn smoothing off for a ticking second hand, leave it on for a sweeping one.

Pitfalls

Watch outA zone that crosses the top of a wrapping scale has from greater than to (300 to 40); only a wrapping scale allows it.
Watch outA rotated face costs a redraw of every tick and label: on a slow display keep the dial small or feed it at a modest rate.
